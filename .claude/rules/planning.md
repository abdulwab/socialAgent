# 📋 Planning Rules

## Planning Format

Har plan is format mein hona chahiye:

```
## 📝 Plan

**Goal:** [User ki request kya hai]

**Steps:**
1. [Step 1]
2. [Step 2]
3. [Step 3]
...

**Files Affected:** [Kaun si files change hongi]
**Estimated Complexity:** Low / Medium / High
```

## Rules

- Chhoti request (1-liner fix) ke liye bhi 2-3 line ka brief plan do
- Badi feature ke liye detailed plan do aur confirm karo
- Plan mein side effects aur risks mention karo
- Ek kaam mukammal karo phir agla shuru karo
